# עדכון — כפתורי סינון לקוחות לפי סטטוס במפת השירות

## מה נוסף
- כפתורי סינון בראש המפה: [הכל] [פעיל] [פרוספקט] [ליד] [עזב]
- כל כפתור מציג גם את מספר הלקוחות בסטטוס
- הסמנים במפה מוצגים לפי הסטטוס הנבחר, עם התמקדות אוטומטית (fitBounds)
- משולב עם החיפוש הקיים (שם/חברה/עיר/טלפון)
- מקרא צבעים מתחת למפה

## איך משלבים בפרויקט הקיים

הקובץ מיועד להחליף את הקובץ הקיים בנתיב:

```
src/app/(protected)/service-map/page.tsx
```

1. חלץ את ה-ZIP.
2. העתק את הקובץ והדבק במקום הקובץ הקיים בפרויקט (או גרור את תיקיית `src` ואשר החלפה).
3. הרץ בדיקה:

```powershell
npm.cmd run build
```

4. אם הבנייה עוברת — העלה ל-GitHub:

```powershell
git add src/app
git commit -m "הוספת סינון סטטוס לקוחות במפת השירות"
git push
```

Vercel תפרוס אוטומטית. אין צורך לגעת במשתני הסביבה.

## הערות טכניות
- הקובץ נטען מ-GET `/api/service-map` (ה-API הקיים שלך ללא שינוי).
- ציפייה לפורמט: `{ customers: [...], counts: {...} }`. אם ה-API שלך מחזיר רק מערך לקוחות, המפה תעבוד גם כך — הספירות יחושבו מקומית רק אם `counts` קיים; אחרת מוצגים מונה כללי.
- ללא תלות בחבילה חיצונית (טעינת Google Maps JS דרך סקריפט).
- המפתח נקרא מ-`NEXT_PUBLIC_GOOGLE_MAPS_API_KEY` (כבר מוגדר אצלך ב-Vercel).
